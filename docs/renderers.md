# 渲染器接口草案

日期：2026-11-11。首轮已按此分层实现轻量单行渲染器。现有接口以 `web/renderers.mjs` 与 `web/renderers/single-line.mjs` 为准；下面保留后续可扩展的职责草案。AMLL 待单独接入。

## 分层

插件采集、后端传输、网页状态和同步时钟独立于渲染器。
统一数据模型由本项目定义，保留行与逐字时间、翻译、音译、背景行和对唱标记；
公共层不导入 AMLL 类型，AMLL 适配器在边界转换字段。
轻量渲染器可以忽略不支持的视觉效果，但不得修改共享原始歌词。

## 接口职责

以下名称是候选契约，不是已经存在的 API。

| 操作 | 输入或返回 | 约定 |
| --- | --- | --- |
| `describe()` | ID、名称、配置描述和能力声明 | 能力标明逐字／逐行、翻译、音译、更新时间需求 |
| `mount(container, context)` | DOM 容器、配置与公共上下文 | 在专属容器初始化，允许异步加载 |
| `setLyrics(document)` | 只读歌词、曲目标识、歌词修订 | 仅全文变化时调用，不处理网络请求 |
| `setPlayback(snapshot)` | 状态、媒体进度、当前行及是否跳转 | 播放、暂停、停止、seek 和校准时更新 |
| `renderFrame(frame)` | 已校准的媒体进度与动画帧间隔 | 可选；仅需要逐帧渲染的实现使用 |
| `configure(options)` | 通用配置及渲染器专用配置 | 命名隔离，不能修改传输和时钟规则 |
| `resize(viewport)` | 容器尺寸 | 布局变化时更新 |
| `clear()` | 无 | 只清理当前展示，保留实例能力 |
| `dispose()` | 无 | 幂等释放实例、监听器、定时器、观察器和图形资源 |

`context` 通过受控公共接口提供状态，不要求每个渲染器注册网络连接。
能力声明需区分纯事件更新和逐帧动画，避免所有方式强制执行动画循环。
具体类型签名和错误处理在实现阶段固定。

## 注册和选择

- 建立注册表，保存渲染器描述及按需加载函数，公共入口不静态导入 AMLL 实现或其 CSS。
- 用户从已注册且可用的方式中选择，其他未实现方式不显示为可选功能。
- 后续可以注册单行字幕、双行字幕或简单多行等轻量实现；它们目前只是候选。
- 配置以渲染器 ID 分区；保存方式和 OBS 输出页如何引用配置另行确定。

## 切换与性能

- 切换由公共管理器协调，保证同一输出区域只有一个活动实例。
- 异步加载使用切换版本校验，快速切换时不让较早完成的旧请求覆盖新选择。
- 新实例从当前完整快照初始化，沿用公共时钟，不重新采集歌词或从零开始播放。
- 旧实例销毁后不得残留动画循环、事件监听器或 DOM；已下载的模块可被浏览器缓存，无需声称卸载代码。
- AMLL 资源和样式使用独立加载边界与容器隔离；验证轻量模式首次加载时不请求其资源。
- 使用 Vue 等自带动画循环的适配器时，公共层和适配器必须确定唯一的帧调度责任。
- 无变化的轻量模式不逐帧更新 DOM，歌词全文只在修订变化时处理。

## 验证重点

接口层检查切换、乱序异步加载、销毁、清空、快照恢复及共用时钟。
在至少两种实际渲染器接入后，对比其资源请求、活动动画循环和所选 OBS 场景下的表现。
首版需接入几种方式、是否自动降级及帧率目标，仍待确认。
